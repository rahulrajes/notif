First, turn on notifications

notif alerts you with a desktop banner the second a poll goes live. This only works if macOS is set to allow Chrome notifications.

Enable it in macOS now
  1. Open System Settings
  2. Click Notifications
  3. Select Google Chrome
  4. Turn Allow notifications ON
  5. Set the style to Alerts (stays on screen)
