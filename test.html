notif test page

This page simulates a poll appearing so you can test the notification without being in a live class. The buttons inject a fake poll element into this page's DOM — the same thing iClicker does when a real poll starts.

What's happening under the hood

// When you click "Simulate poll START":
// 1. A div with data-testid="active-question" appears in the DOM
// 2. Our MutationObserver in content.js would fire onDomChange()
// 3. isPollVisible() finds the element → returns true
// 4. chrome.runtime.sendMessage({ type: 'POLL_STARTED' }) is called
// 5. background.js receives it → chrome.notifications.create() fires
// 6. OS banner appears in the corner of your screen

// NOTE: content.js only runs on student.iclicker.com (per manifest.json).
// On this test page you won't see the full pipeline — but you can test
// background.js directly from the service worker console on chrome://extensions.
