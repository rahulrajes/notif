notif Demo

This page simulates a live poll for Chrome Web Store review. It fires the exact same alert a real iClicker / TopHat poll would.

⚠️ This page must be opened from the notif popup’s “Demo” link so it runs as an extension page. Opened directly as a file, the buttons can’t reach the extension.
Inactive

Clicking a button sends the same runtime message the content script sends on a real poll, so the notification, sound, LIVE badge, and popup are all exercised by the real background script. For demonstration/testing only.
